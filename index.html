GitHub repository

Everything — the live lobby, matchmaking, and the leaderboard — is stored as small JSON files in one GitHub repo via the Contents API. Create a repo (private is fine) and a fine-grained personal access token with Contents: Read & write on that repo.
Semuanya — bilik menunggu langsung, padanan pemain, dan papan pendahulu — disimpan sebagai fail JSON kecil dalam satu repo GitHub. Cipta repo (peribadi tidak mengapa) dan token akses peribadi dengan kebenaran Contents: Read & write.

How this scales to hundreds of players: each player writes their own uniquely-named file to join a lobby — nothing to conflict over. Every client sorts the lobby folder and groups every 5 players by position, so rooms form without any central lock. Polling uses conditional requests (ETags), so unchanged checks don't count against GitHub's rate limit.
Setiap pemain menulis fail sendiri untuk menyertai bilik — tiada percanggahan. Setiap peranti mengisih senarai dan mengumpulkan setiap 5 pemain mengikut kedudukan, jadi bilik terbentuk tanpa sebarang kawalan pusat.

  1. Create a repo first — go to github.com, click + → New repository. Name it e.g. kancil-kira-data. Private or public both work.
    Cipta repo dahulu — pergi ke github.com, klik + → New repository. Namakan cth. kancil-kira-data. Peribadi atau awam kedua-duanya boleh.
  2. Open the token page — go to github.com/settings/tokens?type=beta to create a fine-grained token.
    Buka halaman token — pergi ke github.com/settings/tokens?type=beta untuk mencipta token fine-grained.
  3. Name it & set an expiry — e.g. "Kancil Kira-Kira quiz app". Choose "No expiration" or a date far ahead so it doesn't expire mid-term.
    Namakan dan tetapkan tarikh luput — cth. "Kancil Kira-Kira quiz app". Pilih "No expiration" atau tarikh jauh di hadapan.
  4. Limit it to your repo — under "Repository access", choose "Only select repositories" and pick the one you made.
    Hadkan kepada repo anda — di bawah "Repository access", pilih "Only select repositories" dan pilih repo yang dicipta.
  5. Grant Contents permission — under "Permissions" → "Repository permissions", set Contents to Read and write. Leave everything else as "No access".
    Berikan kebenaran Contents — di bawah "Permissions" → "Repository permissions", tetapkan Contents kepada Read and write. Biarkan yang lain sebagai No access.
  6. Generate & copy it — click "Generate token". Copy it immediately (starts with github_pat_) — it's shown only once.
    Jana dan salin — klik "Generate token". Salin serta-merta (bermula dengan github_pat_) — ia hanya ditunjukkan sekali.
  7. Paste it below & test — fill in your username, repo name, and branch, paste the token in, then click "Test connection".
    Tampal di bawah dan uji — isikan nama pengguna, nama repo, dan cawangan, tampal token, kemudian klik "Test connection".

Rebuild leaderboard index ／ Bina Semula Indeks

Scores are stored one file per submission, so loading the leaderboard means listing many files. Rebuilding compiles a fast top-50 index per grade.
Markah disimpan sebagai satu fail setiap penyerahan, jadi memuatkan papan pendahulu bermakna menyenaraikan banyak fail. Membina semula menghasilkan indeks 50 teratas yang pantas.

Danger zone ／ Zon Bahaya

Deletes every file in a grade's waiting folder. Saved scores are not affected.
Memadam semua fail dalam folder menunggu bagi satu tahun. Markah yang disimpan tidak terjejas.
