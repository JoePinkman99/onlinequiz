Firebase Realtime Database — live matchmaking

This handles the lobby, room formation, and synced countdown/questions. It's built for concurrent writes, so it's what lets hundreds of players join at once without collisions. Create a free project at console.firebase.google.com, enable Realtime Database, and copy the web app config. For a hobby/community deployment, set the database rules to {"rules":{".read":true,".write":true}} — simple and open, fine for this scale but not for sensitive data.

GitHub — durable leaderboard archive

Every finished score is saved as its own small file (no shared file to collide on), so it scales fine even with many players finishing at the same moment. Create a repo and a fine-grained personal access token with Contents: Read & write on that repo. Saved only in this browser's storage.
